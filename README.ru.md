# YaD - Яндекс.Диск TUI

> [English version](README.md)

Терминальный интерфейс для [Яндекс.Диска](https://disk.yandex.ru), построенный на [Bubbletea](https://github.com/charmbracelet/bubbletea).

## Возможности

- Полноэкранный файловый браузер - навигация, открытие папок, постраничный список с индикаторами `▲`/`▼`
- Загрузка и скачивание файлов с отображением прогресса в реальном времени
- Загрузка файлов по URL напрямую на Яндекс.Диск
- Создание папок, переименование и удаление файлов (включая групповые операции)
- Публикация файлов, копирование ссылок в буфер обмена, открытие в браузере
- Управление корзиной - восстановление или безвозвратное удаление
- Информация о диске - использование хранилища с визуальной шкалой
- Авторизация через OAuth 2.0 - пошаговая настройка при первом запуске, токены хранятся локально
- Автоматическое обновление токена - тихое обновление в фоне при истечении срока действия
- Настраиваемая сортировка по умолчанию и восстановление последней открытой папки

## Установка

### go install

```sh
go install github.com/ilyabrin/yad@latest
```

> Бинарник, собранный таким способом, использует ручной ввод токена при аутентификации (клиентский секрет не вшит). Подробнее - в разделе [Аутентификация](#аутентификация).

### Сборка из исходников

```sh
git clone https://github.com/ilyabrin/yad
cd yad
go build -o yad .
```

### Релизная сборка (с OAuth client secret)

Официальные релизы включают клиентский секрет прямо в бинарник при сборке, чтобы полный OAuth-обмен кодом работал автоматически:

```sh
go build \
  -ldflags "-X github.com/ilyabrin/yad/internal/auth.clientSecret=YOUR_SECRET" \
  -o yad .
```

## Аутентификация

При первом запуске `yad` открывает мастер настройки:

1. В терминале отображается ссылка на авторизацию Яндекс OAuth - она автоматически открывается в браузере.
2. Вы разрешаете доступ приложению, и Яндекс показывает короткий код на экране.
3. Вставьте код в терминал - `yad` обменяет его на токены и сохранит в `~/.yad/config.yaml`.

После этого токены загружаются автоматически. Если срок действия токена истёк, `yad` обновит его в фоне через сохранённый refresh token.

### Ручной ввод токена (dev-сборки / CI)

Если клиентский секрет недоступен, мастер попросит вставить долгоживущий токен напрямую. Как вариант, можно задать переменную окружения:

```sh
export YANDEX_DISK_TOKEN=ваш_токен
yad
```

Переменная окружения всегда имеет приоритет над сохранённым токеном - удобно для скриптов и CI.

## Конфигурация

Файл конфигурации хранится по адресу `~/.yad/config.yaml` (права `0600`):

```yaml
# Заполняется автоматически после OAuth-настройки - не редактировать вручную
access_token: "..."
refresh_token: "..."
token_expiry: "2026-06-01T12:00:00Z"

# Опционально: использовать собственное зарегистрированное приложение Яндекс
oauth:
  client_id: "ваш_client_id"
  client_secret: "ваш_client_secret"

# Опционально: настройки интерфейса
default_sort: "-modified"   # name | -name | modified | -modified | size | -size
last_path: "disk:/photos"   # восстанавливается автоматически при выходе; "" = всегда открывать корень
```

Чтобы зарегистрировать собственное приложение, перейдите на [oauth.yandex.ru](https://oauth.yandex.ru) и запросите права `cloud_api:disk.read` и `cloud_api:disk.write`.

## Горячие клавиши

### Файловый браузер

| Клавиша                 | Действие                                           |
| ----------------------- | -------------------------------------------------- |
| `↑` / `k`               | Вверх                                              |
| `↓` / `j`               | Вниз                                               |
| `↵` / `→` / `l`         | Открыть папку                                      |
| `←` / `h` / `Backspace` | Перейти на уровень выше                            |
| `Space`                 | Выбрать / снять выбор                              |
| `Ctrl+A`                | Выбрать всё / снять всё                            |
| `Esc`                   | Сбросить выбор                                     |
| `u`                     | Загрузить файл (2 шага: путь, затем имя)           |
| `U`                     | Загрузить по URL (2 шага: URL, затем имя)          |
| `d`                     | Скачать файл (групповое, если есть выбор)          |
| `n`                     | Создать новую папку                                |
| `r`                     | Переименовать выделенный элемент                   |
| `D`                     | Удалить (групповое, если есть выбор)               |
| `s`                     | Сортировка: имя / дата / размер, прямая и обратная |
| `p`                     | Опубликовать / показать публичную ссылку           |
| `c`                     | Скопировать публичную ссылку в буфер обмена        |
| `o`                     | Открыть публичную ссылку в браузере                |
| `m`                     | Метаданные файла                                   |
| `R` / `Ctrl+R`          | Обновить список                                    |
| `i`                     | Информация о диске                                 |
| `t`                     | Открыть корзину                                    |
| `q` / `Ctrl+C`          | Выйти                                              |

Опубликованные файлы выделяются зелёным фоном и маркером `⇡`.
При нажатии `p` на опубликованном файле показывается ссылка с опциями: `c` скопировать, `o` открыть в браузере, `u` снять публикацию.

### Корзина

| Клавиша           | Действие                                |
| ----------------- | --------------------------------------- |
| `↑` / `k`         | Вверх                                   |
| `↓` / `j`         | Вниз                                    |
| `r`               | Восстановить выделенный элемент         |
| `D`               | Удалить выделенный элемент безвозвратно |
| `E`               | Очистить корзину (удалить всё)          |
| `R` / `Ctrl+R`    | Обновить                                |
| `q` / `←` / `Esc` | Назад к браузеру                        |

### Информация о диске

| Клавиша           | Действие         |
| ----------------- | ---------------- |
| `q` / `←` / `Esc` | Назад к браузеру |

## Замечание о безопасности

OAuth client secret встраивается в бинарник при релизной сборке через флаг `-ldflags`. Это стандартная практика для open-source CLI-инструментов (например, `gh`, `heroku`). Секрет защищает только эндпоинт обмена токена - он не даёт доступа к пользовательским данным. Если вы предпочитаете полный контроль, зарегистрируйте собственное приложение Яндекс и укажите учётные данные в `~/.yad/config.yaml`.
